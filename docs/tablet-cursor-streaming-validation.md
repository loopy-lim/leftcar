## 목적

커서 분리(LCD1 위치 스트림)는 현재 E3(구현·단위 테스트)다. 이 문서는 adb로 연결된 실기기(Lenovo TB710FU)와 실제 호스트에서 수행할 검증을 재현 가능한 절차로 고정한다. 통과 시 docs/EVIDENCE.md에 E6 등급으로 격상 기록한다.

## 검증 1: 토글 옵트인과 오버레이 렌더 (핵심 경로)

절차:

1. 뷰어 앱 카탈로그 → 시청 옵션 카드에서 "원격 커서 로컬 표시" 스위치를 켠다.
2. Mac에서 마우스를 움직인다.
3. 스트림 화면에서 화살표 커서 오버레이가 움직이는지 확인한다. 비디오 속 커서는 숨겨져 있어야 한다.

기록 항목: 오버레이 표시 여부, 비디오 커서 숨김 여부, 지연 체감(대략 ms).

합격 기준: 오버레이가 마우스 이동을 따라 움직이고, 비디오에 커서가 심기지 않는다.

## 검증 2: 기본 off와 폴백 (구버전 호스트 호환)

절차:

1. 토글을 끄고 스트림을 시작한다.
2. 마우스를 움직인다 — 비디오 속 커서가 평소처럼 보이는지 확인한다(회귀 없음).

합격 기준: 토글 off 시 오버레이가 전혀 나타나지 않고 기존 동작과 동일하다.

## 검증 3: 세션 종료 원복 (안전장치)

절차:

1. 토글을 켠 상태로 스트리밍한다(오버레이 동작 확인).
2. 스트림을 종료하거나 케이블을 뽑는다.
3. Mac 화면에서 커서가 즉시 다시 보이는지 확인한다(비디오 캡처 showsCursor 원복).

합격 기준: 세션 종료 후 Mac 로컬 화면에 커서가 남아 보인다(소실 없음).

## 검증 4: Wi-Fi 전환 중 커서 스트림

절차:

1. USB 스트리밍 중 토글 on → 오버레이 동작 확인.
2. 케이블을 제거해 Wi-Fi로 failover한다(docs/usb-physical-validation.md 검증 2 절차 준용).
3. failover 후에도 오버레이가 계속 동작하는지 확인한다(LCH1 재수립 → LCDON 재전송 경로).

합격 기준: Wi-Fi 전환 후 오버레이가 자동으로 재개된다.

## 검증 5: 알려진 간극의 실기 체감 (LCDOFF 미전송)

절차:

1. 스트리밍 중 토글을 on → off로 바꾼다.
2. 비디오 속 커서가 언제 다시 보이는지 기록한다(즉시/재시작 후/세션 종료 후).

합격 기준: Pass/Fail이 아니라 **관측 기록**이 목적 — EVIDENCE에 기록된 간극(토글 off가 LCDOFF 프레임을 보내지 않음)의 실기 체감을 문서화한다. 세션 종료 시 원복은 검증 3에서 보장됨.
