# 연결 안정성 수정 범위

2026-10-03 사용자가 설치된 앱의 E2E 진행을 중단하고 연결 안정성 개선으로 범위를 변경했다. 새 앱 설치, OS 권한 변경, ADB 및 실제 앱 테스트를 진행하지 않는다. 소스와 자동 검증만 다룬다.

- Viewer 제어 요청: 응답 유실 시 상태 변경 명령을 재실행하지 않는다. 명시적으로 허용한 읽기 요청만 연결을 복구한 뒤 재시도한다. 부분 쓰기 실패로 FIFO 응답 대응이 모호해지면 소켓 전체를 폐기한다.
- Viewer 연결 소유권: 공유 재연결의 생명주기는 선택한 Host가 소유한다. 개별 호출 취소는 그 호출의 대기만 취소한다. 비동기 결과와 복구 타이머는 최초 Host 선택과 정확한 창 생명주기가 유지될 때만 적용한다.
- 복구 제한: Android JNI 재부착 반환값을 건강 증거로 사용하지 않는다. 실제 렌더 진행만 복구 예산을 초기화한다. 이전 창의 작업은 세대 전환 전에 취소한다. React가 없는 동안 발생한 복구 알림은 활성 세대별 한 건으로 보류하고 실제 JS 구독 등록 후 전달한다.
- Host 종료: 소스 권한을 철회해도 기존 인증 키와 연결 대상으로 고정된 종료 패킷만 전송할 수 있다. 일반 미디어와 입력의 권한 검사는 유지한다. 내부 재구성 종료가 대체 Viewer 창을 닫지 않도록 일반 종료와 명시적 종료를 구분한다.
- TCP 연결: 프레임의 부분 전송 실패 후 다른 프레임을 이어 보내지 않는다. 전체 핸드셰이크 프레임에 하나의 제한 시간을 적용한다. Windows 입력 경로의 부분 수신과 EOF도 현재 연결의 상태로 처리한다.
- Host 정리: 창의 상태 조회와 독립적인 제한된 주기 작업으로 종료 세션과 유휴 가상 디스플레이 정리를 수행한다. 종료 신호 뒤에는 새 작업을 시작하지 않는다.

각 확정된 실패는 실제 컨트롤러, Activity, 송신기 또는 소켓 경로의 회귀 테스트로 먼저 재현한다. React Doctor 100/100, 타입 검사, 관련 JS/JVM/Rust/Swift 테스트와 플랫폼 대상 컴파일 결과를 기록한다. 소스 검증을 설치된 앱이나 실기기 수용 결과로 표현하지 않는다.
